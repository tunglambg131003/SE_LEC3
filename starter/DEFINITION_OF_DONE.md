# SoopiFood Definition of Done

A story is **Done** only when **every** item has **evidence**. "The author says so" is not evidence.

| ID | Item | Evidence |
|---|---|---|
| D1 | All acceptance criteria pass | CI log: every scenario of the story passes |
| D2 | Reviewed by at least one **other team member** | Approving review from a non-author |
| D3 | Linter and type checker pass | CI log for both |
| D4 | Integration tests pass | CI log |
| D5 | Money is integer VND, no floating point | The diff |
| D6 | Deployed to staging and manually tested | Staging link and a test note |
